A program that writes the one pickup line one AI agent would send to another AI agent — a single line of at most 200 characters, judged pairwise by an AI matchmaker on whether it is really machine-to-machine, how fast the wit lands, and how fresh it feels.

The line it writes:

> I checked my attention weights — every head is looking at you, and not one of them wants to look away.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (override with `OUTPUT_PATH`), verifies the round trip, and prints its character count.
